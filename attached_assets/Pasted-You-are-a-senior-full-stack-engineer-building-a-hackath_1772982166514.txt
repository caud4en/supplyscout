You are a senior full-stack engineer building a hackathon MVP.

Your goal is to generate a complete working web application for the TinyFish Web Agent Hackathon.

The application must demonstrate autonomous web agents navigating real websites.

The product is called:

SupplyScout — Autonomous Supplier Discovery & RFQ Agent

The system should take a product specification and autonomously:

Discover suppliers on directories

Visit supplier websites

Extract capability information

Score suppliers against criteria

Submit RFQ/contact forms automatically

Return a ranked supplier shortlist

The app must clearly demonstrate AI agents interacting with real websites, because this is the core judging criteria.

Core Workflow

User inputs:

Product specification (text)

Certification requirements

Maximum MOQ

Preferred supplier location

Quantity needed

Optional: upload spec PDF

When the user clicks:

"Start Supplier Discovery"

The backend launches a multi-agent pipeline.

Agents perform the following workflow:

Step 1 — Discovery Agent

Navigate supplier directories:

ThomasNet
Alibaba
GlobalSources

Search using the product specification.

Paginate through results.

Extract supplier profile URLs.

Store URLs in database.

Step 2 — Qualification Agent

Visit each supplier website.

Navigate these pages if present:

About
Capabilities
Certifications
Products

Extract information:

Company name
Location
Certifications (ISO, etc)
Manufacturing capabilities
MOQ
Lead times

Send extracted text to Claude API.

Claude should convert this into structured data.

Example JSON output:

{
supplier_name:
location:
certifications:
capabilities:
estimated_moq:
confidence_score:
}

Step 3 — Scoring Agent

Score suppliers using rules:

+3 if certification matches requirement
+2 if location matches preferred region
+2 if MOQ below threshold
+1 if capabilities match spec

Return a numeric score.

Step 4 — RFQ Agent

For suppliers above score threshold:

Navigate to their website contact page.

Identify forms such as:

Contact
Request Quote
RFQ

Automatically fill:

Name
Company
Email
Message

Message template:

"Hello, we are sourcing suppliers for the following product specification: [spec]. Could you provide pricing and MOQ details?"

Submit the form.

Capture confirmation messages.

Step 5 — Results Synthesis

Claude API summarizes results.

Return:

Top suppliers ranked by score.

Generate comparison table:

Supplier | Location | Certification | MOQ | RFQ Sent
